# Spec 035 evidence (R2)

The spec stays Approved, not Implemented. Everything in its R2 scope is built: the tenant authorization server, app registrations, the scope catalogue, the public REST API v1 and its OpenAPI document, rate limits and monthly quotas, event subscriptions over signed webhooks, the MCP server with read tools, resources and confirmed write tools, the external AI client policy, the connected apps page, usage, audit, emergency controls and the developer page. The R3 items (sender-constrained tokens, admin APIs beside SCIM, confirmation through MCP elicitation, MCP prompts, a developer sandbox tenant, a public app gallery) are not started. The spec 035 sections of `docs/architecture/r2-implementation-notes.md` (slices 1 to 5c and T020) hold the defaults, deviations and gaps. Test classes are in `tests/Integration` unless marked unit or e2e. The e2e suites (`api-access.spec.ts`, `mcp-actions.spec.ts`) run in English and Arabic with axe.
