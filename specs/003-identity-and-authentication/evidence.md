# Spec 003 evidence (R0, R1, R2)

Spec 003 is built for every release it targets: development sign-in and the staging test account (R0), Microsoft Entra ID sign-in, Entra ID directory sync and delegated Microsoft Graph access (R1), and Google Workspace, AD FS and SAML 2.0 sign-in, on-premises AD DS sync and the provisioning extension point (R2). A SCIM endpoint is out of scope (FR-008 asks only for the extension point). Test names below are in `tests/Integration` unless another suite is named.
