# Spec 027 evidence (R1)

The spec stays Approved, not Implemented. R1 still lacks the worker that resumes a run interrupted mid-step, the 5 minute run duration limit and per-agent daily limits (FR-015), the tenant link allowlist (FR-014 treats every web address as outside it), the platform switch for a template or tool (FR-020), and the nightly safety run for High risk agents (FR-022). The R2 and R3 parts are not built: L3 approvals, connector and MCP tools (FR-006), org unit policies, scheduled runs (FR-003), the Agent Security Center with anomaly alerts and incidents (FR-023), external AI clients (FR-025) and L4 (FR-024). The spec 020 and 027 section of `docs/architecture/r1-implementation-notes.md` holds the defaults, deviations and gaps.
