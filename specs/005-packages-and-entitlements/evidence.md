# Spec 005 evidence (R0, R2)

Spec 005 is built for every release it targets: the capability catalogue, versioned packages, one subscription per tenant and backend gating (R0), and quotas, add-ons, contract overrides, contract end with grace and read-only mode, and the plan and usage page (R2). Add-ons, overrides, enforcement and contract dates are set through the platform API; there is no platform console screen for them yet (plan.md, R2). Test names below are in `tests/Integration` unless another suite is named.
