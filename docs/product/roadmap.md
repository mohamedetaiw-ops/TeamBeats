# Release roadmap

Adopted 2026-11-04 (Mohamed). Replaces the M/S/L priority labels in the foundation: each requirement is now due in a named release, recorded in its spec's "Target release" field.

| Release | Foundation phases | Contents | Exit criteria |
|---|---|---|---|
| **R0 Internal alpha** | Phase 0 and 1 | Repo, CI, deployment skeleton. Tenant management, organization hierarchy, dev-only sign-in, authorization, entitlement core, audit and admin shell, localization framework (specs 001 to 007) | Cross-tenant and org boundary suites green; constitution checks automated in CI |
| **R1 Pilot** | Phase 2 and 3 (core) | Entra ID sign-in and Entra ID directory sync (users, groups, org mapping). Outlook mail and calendar on the home page with colleague free and busy (spec 018). Experience layer foundation (spec 032 page model and resolver, 10 responsive layouts, 12 page templates with visual variants, visual page builder with keyboard composition and previews by device, direction and persona, component registry; spec 033 semantic tokens, tenant and organization brands with locks, light and dark modes; spec 008 global shell, navigation, quick navigation, shared states and interaction standards). Employee home with personal regions (add, hide, reorder, reset), news and pages, directory and org chart, document library, search, AI Gateway with OpenRouter, tenant model policy and usage view, cited AI assistant, in-app and email notifications. Agent registry and the six launch agent templates (knowledge, HR, IT, content, requests, productivity) at autonomy L0 to L2, where every change waits for the user's confirmation, with review before publish, execution records and emergency controls. AI Evaluation Layer core (spec 034): evaluation registry, golden datasets in Arabic and English, deterministic, judge and trajectory evaluation, scoring and thresholds, evaluation dashboard, and release gates for agent versions, model routes, tools and retrieval configuration. Service catalogue with linked apps, simple form services and one task inbox. Content approval, owners, review dates and critical announcements with acknowledgement; controlled documents and knowledge base; policy register with attestation and policy Q&A; tenant security policy (IP rules, session rules, MFA check, step-up). Arabic and English complete | First design-partner tenant live; dev sign-in absent from production artifact; every live agent, model route and retrieval configuration has a passed release gate |
| **R2 General availability** | Phase 3 (rest), 4 and 6 | Multi-step workflows and service templates, BPMN and DMN process engine (compensation and migration in R3), leave, attendance and HR journeys (onboarding, offboarding, letters, expenses), communities and engagement, sites, page and theme approval with impact reports and rollback, starter wizard for new organizations, custom domains, favorites and command entry point, experience analytics, campaigns across channels, retention and legal hold, brand asset portal, guest users and secure extranet spaces, SIEM streaming, compliance projects, learning, project spaces, mobile app, Microsoft 365 (SharePoint documents, rooms), HR sync and payslip, Teams and mobile push notifications, quotas and metering, Google, SAML and AD FS sign-in, on-premises Active Directory sync, analytics. Agent Studio, customer-created agents, agent marketplace, department agent templates, continuous production evaluation with drift alerts, human review queues, A/B comparisons, business outcome scoring, search relevance evaluation, governed agent actions with approvals (L3), AI budgets, private model endpoints, Agent Security Center. French, Urdu and Hindi complete | Paid packages sellable; performance and penetration tests passed; ISO 27001:2022 certificate and SOC 2 Type I report in hand |
| **R3 Enterprise & Government** | Phase 5 | Bounded agent autonomy inside approved processes (L4), multi-agent handoffs, MCP tools, advanced agent templates, Oracle Fusion and SAP packs, dedicated and on-prem hardening, DR validation, SCIM, customer-managed keys, four-eyes admin changes, national government certifications, records disposition certificates, business KPI tiles on location dashboards, sandboxed tenant-built page components, template recommendations, governed experience experiments, behavioral personalization with consent, personalization and recommendation evaluation, end-to-end evaluation of L4 process runs | First on-prem government deployment |

Open: success measures per release (review finding B4).
